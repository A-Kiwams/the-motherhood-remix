# The Motherhood Remix

A cultural-intelligence experience for expectant mothers, powered by Qloo.

## Technology

- React + Vite
- Node.js + Express
- Qloo API

## Local setup

1. Install dependencies with npm install.
2. Create a local .env file using .env.example as a template.
3. Add your own Qloo API key to .env.
4. Run the API validation script with node test-qloo.mjs.

Never commit your .env file or expose API credentials in frontend code.
